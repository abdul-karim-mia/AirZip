## Description (max 10,000 chars, shown on listing page)

AirZip does one job and does it well: you have a zip (or 7z, or rar...), you want the files out of it. No clutter, no upsells, no accounts, no ads, no tracking.

We built it because most archive tools make you wait through a big install, or bury a simple "extract" button under a file-manager you never asked for. AirZip skips all that — it's a tiny ~2 MB download that opens instantly and just gets out of your way.

**Works with:** ZIP, 7Z (including split archives like .001, .002...), RAR, TAR, GZ, BZ2, XZ, ISO, CAB, LZMA, WIM, and ARJ files.

**What makes it easy to live with:**
- Smart unpacking — one file inside? It lands right next to the archive. Several files? AirZip makes a neat folder for them. No digging through nested folders.
- Handles split archives (.7z.001, .7z.002...) as if they were one file
- Follows your Windows light/dark theme automatically, even if you switch themes mid-extraction
- While extracting, you see exactly what's happening — current file, percent done, and how much has copied
- Plays your Windows completion sound when done, so it stays quiet if you've muted alerts
- For quick extractions, there's no popup at all — the window only shows up if something's actually going to take a moment

**To use it:** right-click any archive file, choose "Open with," and pick AirZip. Want it as your go-to? Set it as the default app for archive files in Windows Settings > Apps > Default apps.

AirZip uses the 7-Zip engine (LGPL) under the hood — see the in-app license notice for details.
