The idea

Windows never got the simple version

Every other extractor wants to be a file manager. AirZip wants to be a verb.

Double-click, done

No dialog asking where to put things, no tree view, no "extract here vs. extract to" decision. AirZip picks the sane destination and unpacks. If it finishes fast, you never even see a window.

Weighs nothing, waits for nothing

2.1 MB of hand-written Win32 C++, statically linked and self-contained. Download it and it runs — the whole thing loads faster than most installers draw their first window.

Nothing leaves your machine

AirZip has no network code at all. No account, no ads, no nag screens, no "upgrade to Pro". It reads the file you gave it and writes the files back out. That's the whole contract.

Features

Small app, careful details

The things you'd only notice if they were missing.

Smart folder handling

One item inside the archive? It lands right beside the original file. Several loose items? AirZip wraps them in a folder named after the archive. No more 40 files sprayed across your Downloads folder — and no pointless foo/foo/foo nesting either.

Split archives, joined for you

Hand it backup.7z.001 and it finds .002, .003 and the rest, then streams them as one continuous file. You never have to think about the volume boundaries.

Follows your Windows theme

Light or dark, picked up from the system — and it switches live, mid-extraction, if you change the theme while it's running. The progress bar even borrows your accent colour straight from DWM.

A window only when it's earned

The progress window is held back for 400 ms. Small archives finish inside that window and never flash anything on screen at all. Big ones get a proper readout: current file, percentage, and megabytes done.

Encrypted archives

Password-protected files get a themed prompt rather than a cryptic failure. Type it once and extraction carries on.

Zip-slip protection

A malicious archive can name its entries ../../Windows/System32/… and try to write outside the folder you chose. AirZip validates every path and rejects absolute paths and .. escapes before writing a byte.

How it works

Three steps, then never again

1

Install it

Grab it from the Microsoft Store, or download the standalone AirZip.exe and run it once. Either way it's under a minute.

2

Make it the default

Run AirZip.exe --install to register all 12 archive types, or right-click any archive → Open with → AirZip. Your previous handlers are backed up and restored on uninstall.

3

Forget it exists

From then on, archives just open. That's the goal — a tool you stop noticing.

FAQ

Questions worth answering

Is it really free? What's the catch?

It's free and the source is public. There is no paid tier, no trial, no ads, and no telemetry — the app contains no networking code at all, so there is nothing for it to send anywhere.

What do I need to install first?

Nothing. AirZip is fully self-contained — it links the C runtime statically and uses only DLLs that ship with Windows itself. Copy the exe onto a fresh machine and it runs straight away.

Store version or the .exe — which should I pick?

The Store version if you just want it to work and stay updated. The .exe if you want something portable, you're offline, or your machine blocks the Store. They are the same program.

What happens to my current archive app if I install AirZip?

Nothing, unless you ask. AirZip only becomes the default handler if you run --install or set it yourself. Even then, the previous handler for each extension is backed up to the registry and restored when you uninstall.

7-Zip, WinRAR and PeaZip all keep working alongside it.

What does AirZip focus on?

Extraction, done exceptionally well. AirZip is a dedicated unpacker — pointing it at an archive and getting the files out is the one job it does, and keeping that scope tight is exactly what keeps it at 2.1 MB and instant to launch.

It sits happily alongside whatever else you use, so nothing in your existing workflow has to change.

Which versions of Windows does it run on?

Windows 10 version 1809 (October 2018) and newer, including Windows 11, on x64.

Why is 7z.dll unpacked into my Temp folder?

The 7-Zip engine is embedded inside the executable as a resource so the download stays a single file. On first run it's written to %TEMP%\AirZip and loaded from there. That's what lets AirZip be one portable exe rather than a folder of files.
